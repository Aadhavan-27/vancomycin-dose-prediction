How the Backend Works

When you click Predict, the browser sends a JSON POST request to /predict on the Flask server. The server:

  1. Computes derived features: BMI, CrCl (Cockcroft-Gault), daily_dose
  2. Builds a DataFrame with the same 12-column feature order the models were trained on
  3. Calls rf.predict(patient_df) — the actual trained Random Forest object
  4. Calls xgb.predict(patient_df) — the actual trained XGBoost object
  5. Computes a traditional PK baseline: (dose × 0.015) − (CrCl × 0.03) + 12
  6. Returns all four values as JSON → frontend renders them instantly

The models are trained once at startup on 500 synthetic samples (same logic as your notebooks, seed=42 for reproducibility). In production, swap in real clinical data.

Better Approaches for This Project
🏆 Best Approach
Non-linear Mixed Effects (NONMEM / Monolix)

The gold standard in clinical PK. Models inter-patient variability explicitly using population PK parameters (Vd, CL). FDA-accepted. Works on small real datasets (<50 patients). Produces individual Bayesian estimates.

💡 Hybrid Approach (Recommended)
PK-ML Hybrid (Mechanistic + Data-Driven)

Use Cockcroft-Gault CrCl and one-compartment PK equations to compute initial estimates, then train ML on residuals. Combines interpretability of PK with predictive power of ML. Works well with limited data.

📈 Improvement to Current
Bayesian Forecasting (MAP)

Feed in a prior (population PK) and update it with 1-2 observed trough measurements using Maximum A Posteriori. This is how real TDM software (DoseMeRx, InsightRx) works. Far more accurate for individual patients.

🚀 Upgrade Current Models
Use Real Data + Cross-Validation

Current notebooks use synthetic data — R² looks good because the model just re-learns its own formula. With real patient data, add nested cross-validation, SHAP explainability, confidence intervals, and calibration curves.

⚠️ Critical Note for Panel: The current synthetic data target is generated using a simple linear formula — so the ML model essentially re-learns that formula. Real clinical performance will be lower. The next step is to source a real vancomycin TDM dataset (MIMIC-III, PharmVar, or institutional data) and rerun the pipeline with proper external validation.
